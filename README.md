# PKGBUILDs
PKGBUILDs I've made that aren't or shouldn't be in the AUR

## Format
PKGBUILDs and related files are each in a branch of this repository named according to their package name, similar to the [GitHub mirror of the AUR](https://github.com/archlinux/aur). Modified PKGBUILDs are also included

## New Packages
| Package                            | Description                   |
| ---------------------------------- | ----------------------------- |
| rose-pine-kvantum-git | Rosé Pine theme for Kvantum |
| rose-pine-korpsvart-gtk-theme-git | [@Fausto-Korpsvart](https://github.com/Fausto-Korpsvart)'s take on the Rose Pine GTK theme |
| vapor-openvr-git | An experimental implementation of an OpenVR runtime on top of OpenXR |
| vrcx-vrcplus-git | [vrcx-git](https://aur.archlinux.org/packages/vrcx-git) with spoofed VRChat+ |
| guxplay-git | A system tray wrapper for UxPlay made with GTK3 |

## Modified Packages
In most cases I'm working on getting my changes into the original AUR package, potentially by adopting it, but they live here for now.
| Package                            | Description                   |
| ---------------------------------- | ----------------------------- |
| equicord-hook ([original](https://aur.archlinux.org/packages/equicord-hook)) | Pacman hook to automatically (re)install Equicord when Discord or Equicord updates |
